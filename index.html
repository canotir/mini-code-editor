Working with Claude

          
    
            
  • Claude reads and writes the files in this project. Its changes appear here live.
    • 
            
  • To mark a spot for Claude, select text and press  or the Comment button. Each comment gets a number such as #3.
    • 
            
  • Then talk to Claude in the main conversation, for example “look at my comments” or “see #3”. Claude replies on the comment and resolves it when it is done.
    • 
            
  • If Claude changes a file while you have unsaved edits, a bar lets you load its version, keep yours, or compare both.
    • 
            
  • A dot marks files that changed since you last opened them. Activity lists each changeset from Claude: review it, apply a proposal, or undo it.
    • 
            
  • In the Explorer menu, mark files or folders as read-only for Claude, as focus files, or pin them to the top.
    •

Press  or F1 to see all commands.
